Quick Start

  1. Click the canvas to add a variable (node).
  2. Click one variable, then another to draw an arrow.
  3. Mark one as exposure (cause) and one as outcome (effect) below.
  4. Check the Causal effect panel on the right for adjustment advice.

Generate DAG from Data

Upload a data file to automatically suggest a causal graph using the PC algorithm (skeleton + collider orientation) combined with LiNGAM-inspired pairwise orientation (non-Gaussianity of residuals).

⚠ Causal discovery is a suggestion, not ground truth. Always validate the result against domain knowledge. Works best with 100+ observations and linear relationships.
